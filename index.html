The Franking Room

Analyzes HTTP headers fetched from a live URL, identifying potential security vulnerabilities or misconfigurations such as missing security headers or insecure cookies, and reports the server version string from the Server header. The franking machine reads the markings on the outside of every envelope before anything inside it is trusted; this tool reads the head of the response the same way.

What it does

The tool fetches the headers of a live URL and reads them for what is missing or unsafe: security headers that are not there, cookies set without protection, and the version string the server announces about itself. Usage, as the README gives it: ./analyze-http-header-analyzer [params]. Its requirements are pandas>=2.1.0 and requests>=2.31.0.
